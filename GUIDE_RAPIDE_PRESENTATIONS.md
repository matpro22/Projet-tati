# 🚀 Guide Rapide - Présentations Produits

## En 3 étapes simples

### 1️⃣ Accéder à l'admin
```
1. Ouvrez votre site
2. Cliquez sur "Admin" dans le menu
3. Connectez-vous :
   - ID : admin
   - MDP : BackZo2024!
```

### 2️⃣ Modifier les présentations
```
1. Cliquez sur l'onglet "Présentations"
2. Choisissez "Page Clubs" ou "Page Particuliers"
3. Modifiez :
   ✏️ Titre
   ✏️ Description
   🖼️ Image ou 🎥 Vidéo
4. Cliquez sur "Enregistrer"
```

### 3️⃣ Voir le résultat
```
1. Allez sur la page Clubs ou Particuliers
2. La nouvelle présentation s'affiche automatiquement !
```

## 📸 Pour ajouter une image

**Option 1 : Image locale**
```
1. Placez votre image dans le dossier /public/
   Exemple : /public/ma-photo.jpg
2. Dans l'admin, entrez : ma-photo.jpg
```

**Option 2 : Image en ligne**
```
1. Utilisez une URL complète
   Exemple : https://example.com/image.jpg
2. Dans l'admin, collez l'URL
```

## 🎥 Pour ajouter une vidéo

**YouTube**
```
1. Copiez l'URL de votre vidéo YouTube
   Exemple : https://www.youtube.com/watch?v=ABC123
2. Dans l'admin :
   - Sélectionnez "Vidéo" dans Type de média
   - Collez l'URL
```

**Vimeo**
```
1. Copiez l'URL de votre vidéo Vimeo
   Exemple : https://vimeo.com/123456789
2. Dans l'admin :
   - Sélectionnez "Vidéo" dans Type de média
   - Collez l'URL
```

## ✅ C'est tout !

Vos modifications sont :
- ✅ Sauvegardées automatiquement dans MongoDB
- ✅ Visibles immédiatement sur le site
- ✅ Cohérentes avec le style BackZo

## 💡 Conseils

**Pour les images :**
- Format recommandé : JPG ou PNG
- Taille recommandée : 1920x1080px (16:9)
- Poids max : 2 MB

**Pour les vidéos :**
- Durée recommandée : 30-60 secondes
- Privilégiez YouTube pour la performance
- Assurez-vous que la vidéo est publique

**Pour le texte :**
- Titre : Court et impactant (max 50 caractères)
- Description : Claire et concise (max 200 caractères)

## 🆘 Besoin d'aide ?

Si vous rencontrez un problème :
1. Vérifiez que MongoDB est bien configuré
2. Vérifiez que l'URL de l'image/vidéo est correcte
3. Consultez la console du navigateur (F12) pour les erreurs
