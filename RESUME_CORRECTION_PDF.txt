🚀 COMMENT UTILISER
────────────────────
1. Démarrer le serveur :
   npm start

2. Créer un devis sur votre site

3. Cliquer sur "Envoyer par email"

4. Le client reçoit un email avec le devis en PDF !


📧 CONFIGURATION EMAIL
───────────────────────
Pour que l'envoi fonctionne, configurez votre fichier .env :

EMAIL_HOST=ssl0.ovh.net
EMAIL_PORT=465
EMAIL_USER=votre-email@backzo.eu
EMAIL_PASS=votre-mot-de-passe
EMAIL_FROM=team@backzo.eu
EMAIL_TO=team@backzo.eu


🧪 TESTER LA GÉNÉRATION PDF
─────────────────────────────
node test-pdf-generation.js
