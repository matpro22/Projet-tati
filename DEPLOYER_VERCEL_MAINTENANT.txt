⚠️ SI ERREUR APRÈS DÉPLOIEMENT
────────────────────────────────

1. Vérifiez les logs Vercel :
   → vercel.com → Votre projet → Deployments
   → Dernier déploiement → Functions → Logs

2. Cherchez les erreurs :
   → "Erreur génération PDF: ..."
   → "Failed to launch..."

3. Si timeout (10 secondes) :
   → Simplifiez le HTML du devis
   → Ou passez à Vercel Pro (timeout 60s)

4. Si "Out of memory" :
   → Passez à Vercel Pro (3 GB RAM)


🔄 FALLBACK AUTOMATIQUE
─────────────────────────

  → Le système envoie automatiquement en HTML
  → Le client reçoit quand même son devis
  → Vous voyez l'erreur dans les logs
