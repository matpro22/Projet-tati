📝 POURQUOI HTML SUR VERCEL ?
══════════════════════════════

Vercel ne fournit pas les bibliothèques système nécessaires
pour Puppeteer/Chromium (libnss3, etc.).

Solutions possibles :
  • Génération PDF côté client (jsPDF)
  • API externe (PDFShift, ~$10/mois)
  • Garder le HTML (gratuit, fonctionne)

Voir : SOLUTION_VERCEL_PDF.md pour plus de détails


✅ AVANTAGES DU HTML
═════════════════════

• Fonctionne immédiatement sur Vercel
• Pas de coût supplémentaire
• Pas de dépendances complexes
• Le client peut le convertir en PDF facilement
• Format professionnel et lisible
