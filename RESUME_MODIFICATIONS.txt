📦 FONCTIONNALITÉ AJOUTÉE
─────────────────────────────────────────────────────────────────
Lorsqu'une commande est marquée "Livrée" dans le panel admin,
une fenêtre demande le numéro de suivi qui est ensuite envoyé
automatiquement au client par email.

✅ FICHIERS MODIFIÉS
─────────────────────────────────────────────────────────────────
1. server.js
   - Route /api/orders/:id/status accepte trackingNumber
   - Fonction sendOrderStatusUpdateEmail mise à jour
   - Email client inclut le numéro de suivi

2. public/index.html
   - Nouvelle modal showTrackingNumberModal()
   - Fonction updateOrderStatus() détecte "delivered"
   - Fonction updateOrderStatusOnBackend() envoie le numéro
   - Affichage du numéro dans showOrderDetails()

3. package.json
   - Nouveau script: npm run test-tracking

🎯 UTILISATION
─────────────────────────────────────────────────────────────────
1. Panel Admin → Commandes
2. Sélectionner "Livré" dans le menu déroulant
3. Saisir le numéro de suivi (optionnel)
4. Confirmer → Email envoyé automatiquement
