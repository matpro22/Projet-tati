🚀 INSTALLATION (3 ÉTAPES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  INSTALLER LES DÉPENDANCES
      
      npm install chrome-aws-lambda puppeteer-core
      
      Ou double-cliquez sur : install-pdf-vercel.bat


  2️⃣  POUSSER SUR GIT
      
      git add .
      git commit -m "Fix: chrome-aws-lambda pour Vercel"
      git push


  3️⃣  ATTENDRE LE REDÉPLOIEMENT
      
      Vercel redéploie automatiquement (~2-3 minutes)
