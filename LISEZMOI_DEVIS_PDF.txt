⚙️  CONFIGURATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Pour l'envoi d'emails, configurez votre fichier .env :

  EMAIL_HOST=smtp.example.com
  EMAIL_PORT=587
  EMAIL_USER=your-email@example.com
  EMAIL_PASS=your-password
  EMAIL_FROM=team@backzo.eu


🎯 UTILISATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Connectez-vous à l'interface admin
  2. Allez dans l'onglet "Créer Devis"
  3. Remplissez les informations client
  4. Ajoutez les lignes du devis
  5. Cliquez sur "Envoyer" 📧

  → Le client reçoit un email avec le devis en PDF !

🔧 DÉPANNAGE

  → npm install puppeteer --legacy-peer-deps

  Le PDF n'est pas généré ?
  → Vérifiez les logs du serveur : npm start
  → Le système utilisera automatiquement le format HTML

  L'email n'est pas envoyé ?
  → Vérifiez la configuration dans .env
  → Testez : npm run test-email
