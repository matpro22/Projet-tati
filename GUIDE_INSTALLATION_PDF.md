# 🚀 Guide Rapide - Installation PDF pour Devis

## Installation en 2 étapes

### Étape 1 : Installer Puppeteer

**Option A - Script automatique (Windows) :**
```
Double-cliquez sur : install-puppeteer.bat
```

**Option B - Ligne de commande :**
```bash
npm install puppeteer
```

### Étape 2 : Redémarrer le serveur

```bash
npm start
```

## ✅ C'est tout !

Les devis sont maintenant envoyés en PDF de haute qualité.

## 🧪 Test rapide

1. Connectez-vous à l'admin
2. Créez un devis de test
3. Envoyez-le par email
4. Vérifiez que la pièce jointe est un PDF

## 📚 Documentation complète

Voir `DOCS/INSTALLATION_PDF_DEVIS.md` pour plus de détails.

## ⚠️ Problème ?

Si l'installation échoue, le système utilisera automatiquement le format HTML (fallback).

---

**Temps d'installation :** ~2 minutes  
**Taille de Puppeteer :** ~300 MB (inclut Chromium)
