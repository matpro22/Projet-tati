CONFIGURATION AUTOMATIQUE
--------------------------
La page détecte automatiquement l'URL du backend :
- En local      : http://localhost:3000
- En production : https://projet-tati.vercel.app

FLUX DE DÉSINSCRIPTION
----------------------
1. Email newsletter contient : https://backzo.eu/unsubscribe?email=xxx
2. Utilisateur clique sur le lien
3. Page backzo.eu/unsubscribe.html se charge
4. JavaScript détecte l'URL du backend
5. Utilisateur confirme la désinscription
6. AJAX POST vers projet-tati.vercel.app/api/newsletter/unsubscribe
7. Backend met à jour MongoDB (unsubscribed: true)
8. Message de succès affiché à l'utilisateur
