💡 RAPPEL - SYSTÈME D'AUTHENTIFICATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Le système utilise :
  • JWT (JSON Web Tokens) pour les sessions
  • bcrypt pour hasher les mots de passe
  • localStorage pour stocker le token
  • Expiration automatique après 24h
  • Déconnexion automatique si token invalide

Classe AdminAuth (admin-auth.js) :
  • login(username, password) - Connexion
  • logout() - Déconnexion
  • isAuthenticated() - Vérifier si connecté
  • verifyToken() - Vérifier le token
  • authenticatedFetch(url, options) - Requête authentifiée
