# 🌟 Guide d'utilisation - Système d'Avis Clients

## Pour les clients

### Comment laisser un avis ?

1. **Recevez votre commande**
   - Attendez que votre commande soit livrée

2. **Consultez votre email**
   - Vous recevrez un email de notification de livraison
   - Cet email contient un bouton vert "⭐ Donner mon avis"

3. **Cliquez sur le bouton**
   - Vous serez redirigé vers une page sécurisée
   - Vos informations de commande sont pré-remplies

4. **Donnez votre avis**
   - Cliquez sur les étoiles pour noter (1 à 5 étoiles)
   - Ajoutez un commentaire si vous le souhaitez (optionnel)
   - Indiquez votre nom ou restez anonyme (optionnel)

5. **Envoyez**
   - Cliquez sur "⭐ Envoyer mon avis"
   - Vous recevrez une confirmation
   - Votre avis sera publié après validation par notre équipe

### Que se passe-t-il après ?

- Votre avis est reçu immédiatement
- Notre équipe le vérifie (généralement sous 24h)
- Une fois approuvé, il apparaît sur notre page d'accueil
- Vous contribuez à aider d'autres clients !

## Pour l'administrateur

### Accéder à la gestion des avis

1. **Connexion**
   - Allez sur votre site BackZo
   - Cliquez sur le point discret en bas de page
   - Connectez-vous avec vos identifiants admin

2. **Onglet Avis clients**
   - Cliquez sur l'onglet "⭐ Avis clients" dans le menu
   - Vous verrez le tableau de bord des avis

### Tableau de bord

Le tableau de bord affiche 4 statistiques clés :

1. **Total avis** : Nombre total d'avis reçus
2. **En attente** : Avis à modérer (en orange)
3. **Approuvés** : Avis publiés (en vert)
4. **Note moyenne** : Moyenne des avis approuvés

### Modérer les avis

#### Approuver un avis
1. Trouvez l'avis dans la liste
2. Lisez le commentaire et vérifiez la note
3. Cliquez sur le bouton vert ✓ (Approuver)
4. Confirmez l'action
5. L'avis apparaît immédiatement sur la page d'accueil

#### Supprimer un avis
1. Trouvez l'avis à supprimer
2. Cliquez sur le bouton rouge 🗑️ (Supprimer)
3. Confirmez la suppression
4. L'avis est définitivement supprimé

### Paramètres des avis

#### Approbation automatique
- **Activé** : Les avis sont publiés immédiatement sans modération
- **Désactivé** : Vous devez approuver chaque avis manuellement (recommandé)

#### Afficher sur la page d'accueil
- **Activé** : Les avis approuvés apparaissent sur la homepage
- **Désactivé** : Les avis ne sont pas affichés publiquement

#### Vérification de commande requise
- **Activé** : Seuls les clients ayant commandé peuvent laisser un avis
- **Désactivé** : N'importe qui peut laisser un avis (non recommandé)

#### Note minimale affichée
- Choisissez la note minimale pour qu'un avis soit affiché
- Par exemple : "3 étoiles et plus" masque les avis 1 et 2 étoiles

#### Nombre maximum d'avis affichés
- Limite le nombre d'avis sur la page d'accueil
- Recommandé : 50 avis maximum

### Bonnes pratiques

#### ✅ À faire
- Modérer les avis rapidement (sous 24h)
- Répondre aux avis négatifs (fonctionnalité à venir)
- Remercier les clients pour leurs retours positifs
- Utiliser les avis pour améliorer vos services
- Garder l'approbation manuelle activée au début

#### ❌ À éviter
- Supprimer les avis négatifs légitimes
- Laisser des avis en attente trop longtemps
- Activer l'approbation automatique sans surveillance
- Afficher uniquement les 5 étoiles (perte de crédibilité)

### Notifications

#### Vous recevez un email quand :
- Un nouveau client soumet un avis
- L'email contient :
  - Le nom du client
  - La note donnée
  - Le commentaire
  - Le numéro de commande
  - Un rappel d'aller modérer

### Actualiser les données

- Cliquez sur le bouton "🔄 Actualiser" en haut à droite
- Les statistiques et la liste se mettent à jour
- Utile après avoir modéré plusieurs avis

### Sauvegarder les paramètres

1. Modifiez les paramètres selon vos besoins
2. Cliquez sur "Enregistrer les paramètres →" en bas
3. Un message de confirmation apparaît
4. Les changements sont appliqués immédiatement

## Questions fréquentes

### Combien de temps un avis reste-t-il affiché ?
Les avis restent affichés indéfiniment, sauf si vous les supprimez manuellement.

### Puis-je modifier un avis ?
Non, mais vous pouvez le supprimer et demander au client d'en soumettre un nouveau.

### Les clients peuvent-ils laisser plusieurs avis ?
Non, un seul avis par commande est autorisé.

### Que faire si un avis est inapproprié ?
Supprimez-le immédiatement et contactez le client si nécessaire.

### Les avis sont-ils anonymes ?
Le client peut choisir de rester anonyme ou d'indiquer son nom.

### Puis-je exporter les avis ?
Cette fonctionnalité sera ajoutée prochainement.

## Support technique

### Problème : Les avis ne s'affichent pas sur la homepage
1. Vérifiez que "Afficher sur la page d'accueil" est activé
2. Vérifiez qu'il y a des avis approuvés
3. Videz le cache de votre navigateur
4. Contactez le support si le problème persiste

### Problème : Les clients ne reçoivent pas l'email
1. Vérifiez que la commande est au statut "Livrée"
2. Vérifiez l'adresse email du client
3. Vérifiez les paramètres email du serveur
4. Consultez les logs du serveur

### Problème : Impossible d'approuver un avis
1. Vérifiez votre connexion admin
2. Actualisez la page
3. Reconnectez-vous si nécessaire
4. Contactez le support technique
