# 🚀 Démarrage Rapide - Devis PDF

## Installation en 3 étapes

### Étape 1 : Installer Puppeteer
```bash
npm install puppeteer
```
Ou double-cliquez sur `install-puppeteer.bat` (Windows)

### Étape 2 : Démarrer le serveur
```bash
npm start
```

### Étape 3 : Tester
1. Ouvrez http://localhost:3000
2. Connectez-vous à l'admin
3. Créez un devis de test
4. Envoyez-le par email

## ✅ C'est fait !

Les devis sont maintenant envoyés en PDF professionnel.
