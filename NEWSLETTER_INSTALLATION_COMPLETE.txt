🚀 DÉMARRAGE RAPIDE :

1. Configuration (.env) :
   ─────────────────────────────────────────────────────────────────────────
   EMAIL_HOST=ssl0.ovh.net
   EMAIL_PORT=465
   EMAIL_USER=team@backzo.eu
   EMAIL_PASS=votre_mot_de_passe
   EMAIL_FROM=team@backzo.eu
   MONGODB_URI=votre_uri_mongodb
   ─────────────────────────────────────────────────────────────────────────

2. Démarrer le serveur :
   npm start

3. Tester le système :
   node "Fichier de test/test-newsletter.js"

4. Utiliser :
   - Visiteurs : Footer du site → Entrer email → S'inscrire
   - Admin : /admin → Onglet "Newsletter" 📧

📧 EXEMPLE D'UTILISATION :

Envoyer une newsletter :
  1. Connexion admin (/admin)
  2. Onglet "Newsletter"
  3. Remplir le formulaire :
     ┌───────────────────────────────────────────────────────────────────────┐
     │ Sujet : 🎉 Nouveautés BackZo - Janvier 2024                          │
     │                                                                       │
     │ Message :                                                             │
     │ Bonjour,                                                              │
     │                                                                       │
     │ Nous sommes ravis de vous présenter nos nouveautés...                │
     │                                                                       │
     │ Cordialement,                                                         │
     │ L'équipe BackZo                                                       │
     └───────────────────────────────────────────────────────────────────────┘
  4. Cliquer sur "Aperçu" (optionnel)
  5. Cliquer sur "Envoyer à tous les abonnés"
  6. Confirmer
