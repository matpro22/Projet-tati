🐛 PROBLÈME DÉTECTÉ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Erreur 404 lors de la connexion admin :
  POST 404 projet-tati.vercel.app/api/api/admin/login
                                   ^^^^^^^^
                                   Double /api/


🔍 CAUSE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dans public/admin-auth.js :
  ❌ fetch(`${API_URL}/api/admin/login`)

Alors que API_URL contient déjà /api :
  const API_URL = 'https://projet-tati.vercel.app/api'

Résultat : /api + /api/admin/login = /api/api/admin/login ❌


✅ CORRECTION APPLIQUÉE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Fichier : public/admin-auth.js

Ligne ~31 (fonction login) :
  ❌ AVANT : fetch(`${API_URL}/api/admin/login`)
  ✅ APRÈS : fetch(`${API_URL}/admin/login`)

Ligne ~81 (fonction verifyToken) :
  ❌ AVANT : fetch(`${API_URL}/api/admin/verify`)
  ✅ APRÈS : fetch(`${API_URL}/admin/verify`)

1. Installez les dépendances :
   npm install

2. Configurez l'authentification :
   npm run setup-auth

3. Testez :
   npm run test-auth

4. Démarrez :
   npm start

Pour Vercel, configurez les variables d'environnement :

  • ADMIN_PASSWORD
  • JWT_SECRET
