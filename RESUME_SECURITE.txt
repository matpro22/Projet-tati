⚡ INSTALLATION RAPIDE (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Installer les dépendances
   npm install

2. Configurer l'authentification
   npm run setup-auth
   (Suivez les instructions)

3. Tester
   npm run test-auth

4. Démarrer
   npm start

5. Se connecter
   http://localhost:3000 → Cliquez sur le point dans le footer

🚀 DÉPLOIEMENT SUR VERCEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Dashboard Vercel → Settings → Environment Variables

2. Ajoutez :
   ADMIN_USERNAME = admin
   ADMIN_PASSWORD = VotreMotDePasseSecurise
   JWT_SECRET = (généré avec npm run generate-secret)

3. Redéployez

4. Testez la connexion

Voir VERCEL_AUTH_SETUP.md pour plus de détails

→ Exécutez : npm install

"ADMIN_PASSWORD non défini"
→ Exécutez : npm run setup-auth

"Identifiant ou mot de passe incorrect"
→ Vérifiez les valeurs dans .env

"Token invalide ou expiré"
→ Reconnectez-vous (session expirée après 24h)
