# 🚀 Démarrage Rapide - Présentations Produits

## ✨ Nouvelle fonctionnalité ajoutée !

Des sections de présentation produit ont été ajoutées sur les pages **Clubs** et **Particuliers**. Vous pouvez maintenant les personnaliser depuis l'admin !

---

## 🎯 En 3 étapes

### 1️⃣ Accédez à l'admin
- Cliquez sur **"Admin"** dans le menu
- Connectez-vous (admin / BackZo2024!)

### 2️⃣ Ouvrez l'onglet Présentations
- Cliquez sur **"Présentations"** (icône 📺)
- Vous verrez deux sections : Clubs et Particuliers

### 3️⃣ Modifiez et enregistrez
- Écrivez votre texte de présentation
- Ajoutez une image ou vidéo YouTube
- Cliquez sur **"Enregistrer"**

---

## 📍 Où apparaissent les présentations ?

### Page Clubs
```
Hero → [PRÉSENTATION] → Comment ça marche → ...
```

### Page Particuliers
```
Hero → [PRÉSENTATION] → Configurateur → ...
```

---

## 💡 Exemple rapide

**Texte :**
```html
<p>BackZo révolutionne le <strong>flocage sportif</strong>.</p>
<p>Technologie amovible unique pour les clubs.</p>
```

**Média :**
- Image : `1.jpg`
- Vidéo : `https://youtube.com/watch?v=...`
