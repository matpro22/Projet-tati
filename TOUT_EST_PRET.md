## 🎨 Personnalisation rapide

### Changer les couleurs
```css
/* Ligne ~40 de Untitled-1.html */
:root {
  --green: #b8ff57;  /* ← Votre couleur */
}
```

### Changer le nom du site
```javascript
// Ligne ~1540 de Untitled-1.html
settings: {
  siteName: 'BackZo',  /* ← Votre nom */
}
```

### Ajouter un produit
```javascript
// Ligne ~1550 de Untitled-1.html
const PRODUCTS = [
  {
    id: 'mon-produit',
    name: 'Mon Produit',
    price: 20,
    category: 'particuliers',
    desc: 'Description',
    stock: 100
  }
];
```
